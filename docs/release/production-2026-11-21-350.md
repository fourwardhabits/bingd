Founder-approved narrow production OTA ("Final Title-Page Actions & Overflow Menu", 2026-11-21). Client-only: no migration, no server or RPC change, no native dependency.

## What shipped
- [#350](https://github.com/fourwardhabits/bingd/pull/350), squash-merged as `1101b029`.
- **Row** (both layouts, movie / whole show / season): exactly three controls.
  - Unranked: Rank Movie / Show / Season, the bookmark, then ⋯.
  - Ranked: Log rewatch, the bookmark, then ⋯.
  - The ⋯ moved from the top bar into the row; the top bar keeps Back only.
- **⋯ menu, in order:** Recommend to a friend · Share off bingd · Add to list · Edit ranking / Add note (Edit log / … when logged but unranked; absent with no log) · rule · Remove from collection (existing confirmation).
- Recommend and Share are separate rows. Share off bingd uses the same message as the Recommend sheet's button (`share-title.ts`).
- The editing row opens the existing log sheet with nothing expanded. A ranking correction uses `p_new_watch: false`; a note or review edit sends one `save_note` and no `rank_*`/`log_*` call; cancel writes nothing.
- Rerank, Log another watch, Who I watched with and the separate note row were removed from the menu. A rewatch is only the row's Log rewatch.
- On iOS every menu row waits for the menu to dismiss before presenting its sheet, the share sheet or the removal alert.

Not included: #346 (superseded, closed), #347, #348, #322, #330. The pending 1.2.0 store build was not touched.
