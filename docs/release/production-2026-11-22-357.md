# Production release 2026-11-22: two posts per shared window (`20261130001000`, #357 + #358 + #359)

Released under the founder's 2026-11-22 "Final Feed Grouping Correction + Consistent Watchlist Buttons" decisions. Those decisions replace the mixed-session spec of #354, and the founder approved fast-tracking this focused change to production through the existing guarded process once the checks were green and the data correction was shown to be safe.

## Changes
- [#357](https://github.com/fourwardhabits/bingd/pull/357), squash-merged as `ef5258ec`.
  - **Grouping.** Each author has one fixed 30-minute window, shared by rankings and saves, with at most one ranking post and one watchlist post in it.
  - **Reviews.** They play no part in grouping.
  - **Bookmark.** The reader's own bookmark is on every Feed title poster.
  - **Correction tooling.** It adds the operator-only historical split.
  - **Checks.** CI, the concurrency suite and Codex were clean on `fc4ff528`.
- [#358](https://github.com/fourwardhabits/bingd/pull/358), squash-merged as `6b7f04fc`, amends the unapplied `20261130001000` in place.
  - **What it fixed.** The Database races run on `ef5258ec` (run 44974811085) failed WG1 intermittently: two first saves from two devices could leave two watchlist posts.
  - **Cause.** The save read its window with `now()`, and `now()` is the transaction's start time. A save that started first but locked second therefore missed the window the other save had committed.
  - **Fix.** The save now claims its window the way every other writer does.
  - **Tests.** WG5 and RS5 force that interleaving, and mutant 21 is detected. 750 looped race runs passed. Codex was clean on `0674cfa1`.
- [#359](https://github.com/fourwardhabits/bingd/pull/359), squash-merged as `98f55fa0`, is test-only.
  - **What it fixed.** The Release gate on `6b7f04fc` (run 44978345973) failed `FeedEngagement` › "a grouped post on its fallback card".
  - **Cause.** Since #357 a rail's headline also reads "3 others" while its previews load, so three tests asserted "no rail" while the placeholder rail was still showing.
  - **Fix.** The tests now wait for the headline with no rail.
  - **Checks.** CI and the Release gate (run 44979946444) passed, and Codex was clean on `99e7b275`.
